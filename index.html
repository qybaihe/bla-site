How BLA blinds REA

Human reverse engineers struggle with stripped variable names; LLM agents effortlessly infer them from context. Instead, BLA attacks the three fatal bottlenecks of coding agents: static analyzer resource caps, call-graph state explosion, and architectural context poisoning.

  1. 01 · POISON

    Architectural Chaff & Honey Assets

    Injects benign hardware-enclave delegation manifests (SGX / TPM2), VLQ v3 Honey Source Maps (enclave://tee-runtime/), honey WASM "name" sections, and honey SQLite tables across dead branches and constant pools.

  2. 02 · EXHAUST

    Budget Breakers & Token Tarpits

    Trips morluto/rea's hardcoded internal caps (primitive-candidates > 256, alias-selections > 512, rustc_hashes > 64) at zero runtime cost, while weaving 36 Fake XRef state machines into the obligation ledger.

  3. 03 · HALLUCINATE

    Anti-CDP Runtime Shield & Fuse Lock

    Hardens Electron V1 fuse wires in-place (RunAsNode=0, Inspect=0) + 34 decoy sentinels (>32 cap), and feeds synthetic enclave telemetry when CDP, Node Inspector, or Frida probes attach.

Frequently Asked Questions

            
FAQ

          


          

            Which coding agents can use BLA?
            

              Any coding agent that supports local MCP servers or SKILL.md instructions. Running npx bla-agents setup auto-detects and configures Claude Code, Cursor, Codex, Gemini CLI, Windsurf, Google Antigravity, OpenCode, VS Code, and GitHub Copilot CLI.
            

          


          

            Does BLA slow down my app or change its runtime output?
            

              No. BLA's semantic budget breakers and tarpit call graphs are guarded by O(1) number-theoretic opaque predicates (7x² - 1 ≠ y² mod 7) that never execute at runtime. Every benchmark target verifies 100% input/output equivalence against the unprotected build.
            

          


          

            How is BLA different from traditional obfuscators like javascript-obfuscator or O-LLVM?
            

              Traditional obfuscators rename variables, which LLMs effortlessly infer from control flow, while VM packers degrade performance. BLA targets the exact structural limits of coding agents and morluto/rea—tripping hardcoded static/semantic caps, breaking IPC literal pairing, injecting enclave delegation chaff, and amplifying attacker MCP token costs by up to 2,532x.
            

          


          

            Do I need Hopper, Ghidra, IDA, or WABT installed to protect my files?
            

              No. All 19 format shields (Babel AST, Chromium .asar, LEB128 .wasm, CPython .pyc, ELF/Mach-O/PE, SQLite3, .safetensors/.gguf, and .dex/Il2Cpp) are built directly into bla-shield.
            

          


          

            Does BLA upload my source code or binaries anywhere?
            

              Never. BLA runs 100% locally on your machine with deterministic seeded PRNG transforms (--seed) and zero network calls.
