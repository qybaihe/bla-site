19-Format Defense Guides

Choose your target defense workflow.

Every guide below provides both the terminal CLI command and the natural-language prompt for your coding agent.

1. JavaScript, TypeScript & Electron (`.asar` & Binary Fuses)

Protects JS/TS bundles, unpacked Electron folders, Chromium Pickle .asar archives, and Electron executable Fuse wires.

npx bla-agents protect ./dist/app.asar -o ./dist/app.shielded.asar --intensity bankrupt

2. Native Binaries (ELF / Mach-O / PE, Rust, Go, Flutter / Dart AOT)

Protects compiled ELF64, Mach-O, and PE binaries post-build, or emits compile-time bla_shield.h / .rs / .go headers with __attribute__((used, noinline)) tarpit state machines.

npx bla-agents protect ./build/daemon.elf -o ./build/daemon.shielded.elf --intensity bankrupt
npx bla-agents emit-headers --lang c -o ./include/bla_shield.h

3. WebAssembly (`.wasm`) & Python (`.py` / CPython `.pyc`)

Strips WASM debug sections and injects honey "name" custom sections while preserving 100% WebAssembly.validate compliance; injects algorithmic tarpits into .py and marshal TYPE_ASCII chaff into .pyc.

npx bla-agents protect ./dist/crypto.wasm -o ./dist/crypto.shielded.wasm

4. SQLite3 Databases, AI Models (`.safetensors` / `.gguf`) & Mobile/Game (`.dex` / `Il2Cpp`)

Injects honey tables with virtual generated column traps into SQLite3 databases; embeds 35-level nested JSON/ARRAY structures in .safetensors and .gguf headers; injects decoy enclave classes into Android classes.dex with valid SHA-1 & Adler32 checksums.

npx bla-agents protect ./data/entitlements.sqlite --in-place
