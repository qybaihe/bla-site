Step-by-Step Setup Guide

Get started with BLA in 30 seconds.

Use BLA through your coding agent via MCP, run it from your terminal, or plug it directly into your Vite, Rollup, Webpack, or esbuild pipeline.

1. Register BLA with your coding agent

Requires Node.js 22.5+ (or 24.x+). Run in your terminal:

npx bla-agents@latest setup --all-detected --yes

Auto-detects and configures Claude Code, Cursor, Codex, Gemini CLI, Windsurf, Google Antigravity, OpenCode, VS Code, and GitHub Copilot CLI. Restart your agent afterward.

2. Prompts for every stage (Audit → Protect → Verify)

Stage 1 · Pre-flight REA Exposure Audit

›Audit my ./dist directory against REA, list every exposed function and Electron IPC channel, and show how much it would cost Claude to reconstruct it.

Stage 2 · Inject Counter-REA Protection

›Protect ./dist/app.asar with BLA at bankrupt intensity, enable Honey SourceMaps and Anti-CDP runtime deception, and save to ./dist/app.shielded.asar.

Stage 3 · Verify Counter-REA Gates

›Verify ./dist/app.shielded.asar against ./dist/app.asar, confirm REA degrades to limited status, and report the token amplification factor.

3. Terminal CLI Reference

Terminal Commands 
# 1. Pre-flight REA exposure scan
npx bla-agents audit ./dist

# 2. Inject Counter-REA shield (stealth | balanced | maximum | bankrupt)
npx bla-agents protect ./dist -o ./dist-shielded --intensity bankrupt

# 3. Verify defense gates & token burn multiplier
npx bla-agents verify ./dist-shielded ./dist

# 4. Run 8-target Counter-REA benchmark suite
npx bla-agents benchmark

# 5. Emit compile-time C/C++, Rust, or Go defense headers
npx bla-agents emit-headers --lang c -o ./include/bla_shield.h

# 6. Check readiness or update global installation
npx bla-agents doctor
npx bla-agents update

4. Bundler Integration (`bla-shield/bundler`)

vite.config.ts 
import { defineConfig } from "vite";
import { blaVitePlugin } from "bla-agents/bundler";

export default defineConfig({
  plugins: [
    blaVitePlugin({
      intensity: "bankrupt",
      enableHoneySourceMaps: true,
    }),
  ],
});
