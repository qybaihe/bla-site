Quick Start

Connect Your Agent. Defend in One Click.

Requires Node.js 22.13+ or 24+. No external compilers or commercial packers needed.

Step 1 · Agent MCP Setup

Register BLA with Your Coding Agent

Automatically configures Claude Code, Cursor, Codex, Windsurf, Gemini CLI, and Antigravity with the bla MCP server and blind-llm-agents skill. 

npx bla-agents@latest setup --all-detected --yes
Step 2 · One-Click Hardening

Run the 5-Stage Counter-REA Pipeline

Executes source-map exposure scan, 16-vector REA audit, bankrupt exhaustion + deception shield injection, invariant verification, and manifest signing in one command. 

npx bla-agents@latest defend ./dist --manifest

Build Bundler Plugin

Automatic Build-Time Shielding

Works out of the box with Vite, Rollup, Webpack, and esbuild:

import { blaVitePlugin } from "bla-agents/bundler";

export default {
  plugins: [blaVitePlugin({ intensity: "bankrupt" })],
};
